# Cipher Atlas · 现代密码学知识图谱

本地知识网站，React + Vite + Three.js，24 个主题、5 个分类、4 个交互实验。

## 本地运行

```sh
npm install
npm run dev -- --port 5188
```

浏览器打开 http://127.0.0.1:5188/ 。生产构建：`npm run build`。

## 功能

- SVG 知识图谱：语义关联、分类筛选、关键词搜索、拖动与缩放。
- 技术百科：原理、流程、应用、误区、官方资料链接及理解检查。
- Web Crypto SHA-256 实际计算与逐位差异统计。
- 教学参数 Diffie–Hellman 计算和四步 TLS 1.3 握手。
- Three.js 三维格点模型，鼠标或触摸旋转。仅用于概念直觉，不是实际 ML-KEM 密钥空间。
- 三条学习路径、翻转闪卡和 localStorage 学习记录。
- 响应式界面、键盘焦点、弹窗 Escape 关闭及焦点约束、减少动态效果支持。

内容以各条目链接的 NIST、IETF、W3C 和协议官方文档为依据。前沿密码与互联网普遍使用的技术分区展示。小参数实验不供生产加密使用。

项目独立保存在 cryptography 目录。仅本地运行，未配置托管或部署。
